# WSDeckBuilder 卡表資料

的線上更新資料源。**這個 repo 只是我自己手機的資料來源，不是給人使用的專案。**

```
cards/          各作品卡表（App 逐部比對 data_version，只下載有變動的）
manifest.json   版本目錄，由 CI 自動產生，不要手改
tools/          產生與檢查 manifest 的腳本
```
