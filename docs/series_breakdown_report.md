# 系列分彈正式名稱資料報告

這份報告提供程式端做「同系列不同彈分開分類」的資料依據。翻譯資料本身不用改 UI，也不用翻譯《》特徵名。

## 建議規則

- 以每張卡的 `id` 或 `printings[].id` 解析彈別。
- product code 取卡號最後一個 `-` 前面的部分，例如 `SFN/S108-001` -> `SFN/S108`。
- 同一張卡有多刷版時，仍以唯一卡 `id` 計一次；若要顯示刷版數，另看 `printing_count`。
- `official_display_name_jp` 是從 WS 官方卡表 API 對到的主要正式名稱，適合作為子分類顯示依據。
- `official_expansions` 保留同一 product code 底下所有官方 expansion，例如同代碼同時有 TD、補充包、PR。
- 若同一 product code 同時有 TD 與補充包，預設主顯示名優先用補充包／Premium／Extra／其他商品，再用 TD，最後才用 PR。

## 交付檔案

- `docs/series_breakdown.json`：程式可直接讀的完整 mapping，schema_version 已更新為 2。
- `docs/series_breakdown_report.md`：人工檢查用摘要。
